# 海大海廢社群地圖

這是一個學習用途的 MVP 網站，讓使用者在國立臺灣海洋大學與基隆周邊地圖上回報海洋廢棄物、活動與淨灘資訊。

## 已完成功能

- Leaflet 互動式地圖，預設中心在海洋大學附近。
- 「我的位置」按鈕可使用裝置 GPS 定位，並將地圖移到目前位置。
- 「新增標記」可選擇使用當前 GPS 位置或地圖手動點擊。
- 分類篩選：全部、活動、垃圾、淨灘。
- 可勾選「顯示已清理區」，即時切換已清理垃圾點位。
- 垃圾程度欄位只在垃圾分類顯示。
- 垃圾回報可填預估袋數 / 數量或重量；勾選一般塑膠時前端即時計算預估碳減量並存入資料庫。
- 設定標點時，地圖會以灰色點預覽目前選定位置。
- 垃圾回報可勾選具體垃圾類別與特殊危險廢棄物，系統會自動判定風險等級。
- 高風險垃圾、爆裂物、醫療廢棄物、毒化物、動物屍體、保育類動物或水質污染會顯示安全警示與通報專線。
- 垃圾圖標會依嚴重程度顯示不同顏色，已清理點位會改用綠色勾勾。
- 垃圾標記可送出「回報已清除」，達到多人確認門檻後自動轉入清除區。
- 輕度垃圾 2 天、中度垃圾 3 天後會自動轉入清除區；重度垃圾不自動清理。
- 活動與淨灘可填開始與結束時間。
- 活動與淨灘過期後會自動歸檔，預設隱藏；可勾選「顯示歷史活動」重新載入。
- 淨灘活動可填主辦單位、信箱、活動地點、活動 / 報名網址與人數上限。
- 淨灘活動支援免登入報名 / 取消報名，並顯示報名人數進度條。
- 圖片可多張上傳，限制圖片 MIME type 與單張 5MB 大小。
- 側欄顯示淨灘活動，並依開始時間排序。
- 標記彈窗與淨灘清單都能留言。
- 彈窗內容會限制高度與圖片大小，完整內容可透過「完整敘述」開啟。
- 完整敘述面板會自動換行並避免橫向滾動；點擊發布者會以使用者資料面板顯示公開資料。
- 瀏覽器第一次造訪會以 `localStorage` 建立裝置識別，發文時記錄 owner。
- 原發文裝置可在標記彈窗或「個人主頁」編輯、刪除自己的貼文。
- 「個人主頁」可設定顯示暱稱、個人敘述或聯繫方式，並列出自己的貼文。
- 點擊標記中的發布者可查看公開個人資料。
- 前端顯示使用 `escapeHtml` 避免把留言當成 HTML 執行。
- 後端使用 Express、Mongoose、Multer 與 dotenv。

## 啟動方式

1. 安裝依賴：

   ```bash
   npm install
   ```

2. 建立 `.env`：

   ```bash
   copy .env.example .env
   ```

3. 確認 MongoDB 已啟動，並視需要修改 `.env` 的 `MONGODB_URI`。

   清理確認門檻會依資料庫中的曾使用人數自動計算，公式是 `max(1, ceil(曾使用人數 / 100))`。

4. 啟動伺服器：

   ```bash
   npm start
   ```

5. 開啟 `http://localhost:3000`。

## API

- `GET /api/markers`
- `GET /api/markers?includeExpired=true`
- `GET /api/markers/me`
- `POST /api/markers`
- `PUT /api/markers/:id`
- `DELETE /api/markers/:id`
- `POST /api/markers/:id/join`
- `GET /api/users/me`
- `PUT /api/users/me`
- `GET /api/users/:userKey`
- `POST /api/markers/:id/comments`
- `POST /api/markers/:id/confirm-clean`

詳細欄位請看 `SCHEMA.md`。
